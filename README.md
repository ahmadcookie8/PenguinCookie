# PenguinCookie 🐧

Welcome to the main landing page for **PenguinCookie.ca** — a hub for games, projects, and creative work by Ahmad.

## About

PenguinCookie is a modern, interactive landing page that showcases games, projects, and other creative endeavors. The site is built with a focus on great user experience, featuring a responsive design and smooth interactions.

**Website:** [penguincookie.ca](https://penguincookie.ca)

## Features

- 🎨 **Modern Design** - Built with Tailwind CSS for a sleek and responsive UI
- 🌓 **Dark/Light Mode** - Toggle between themes with persistent storage
- ⚡ **Fast & Optimized** - Built with Vite for instant development and optimized production builds
- 📱 **Responsive** - Works seamlessly across all device sizes
- 🔧 **TypeScript** - Fully typed for better development experience
- ⚛️ **React-powered** - Component-based architecture for maintainability

## Tech Stack

- **Frontend Framework:** [React](https://react.dev) 18.2.0
- **Build Tool:** [Vite](https://vitejs.dev) 5.4.19
- **Styling:** [Tailwind CSS](https://tailwindcss.com) 4.1.8
- **Language:** [TypeScript](https://www.typescriptlang.org) 5.1.3
- **Deployment:** [Vercel](https://vercel.com)

## Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmadcookie8/PenguinCookie.git
   cd PenguinCookie
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Create an optimized production build:
```bash
npm run build
```

### Preview

Preview the production build locally:
```bash
npm run preview
```

The site remembers your theme preference using localStorage. The theme can be toggled and will persist across sessions.
